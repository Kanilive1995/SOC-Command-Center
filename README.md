# SOC Command Center

## Project Overview
SOC Command Center is a Python-based command-line application designed to simulate basic Security Operations Center (SOC) alert monitoring and tracking.

The project focuses on building practical Python skills while exploring how security analysts classify alerts, monitor suspicious activity, and track investigation workloads.

## Current Features
- Analyst username input
- Security monitoring status display
- Alert severity classification (Critical, High, Medium, Low)
- Simulated security alert list
- Automated alert classification using Python loops and conditional statements
- Critical alert counter
- Total alert tracking
- Remaining alert calculation

## Technologies Used
- Python 3
- PyCharm
- Git and GitHub

## How to Run

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project directory:
   ```bash
   cd SOC-Command-Center
   ```

3. Run the application:
   ```bash
   python3 main.py
   ```

## Project Goals
This project is an ongoing learning experience focused on Python programming, security alert monitoring, and foundational SOC workflows.

Future improvements may include:
- Interactive alert investigations
- Analyst decisions to resolve or escalate alerts
- Investigation scoring
- Security event logging
- Expanded alert simulation
